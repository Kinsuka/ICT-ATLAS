Référence — Dictionnaire pédagogique ICT : vocabulaire détaillé

Guide autonome
Objectif de cette page : ne pas seulement donner une définition, mais expliquer comment chaque mot sert à prendre ou refuser une décision. Chaque terme est présenté avec sa définition, son utilité, sa limite, l’erreur fréquente et un mini-exemple concret.

OHLC / Bougie

Définition : Open, High, Low, Close sont les quatre données d’une bougie. Le corps montre la différence entre ouverture et clôture ; les mèches montrent les extrêmes.

À quoi ça sert : lire précisément où le prix a ouvert, rejeté, clôturé et où une liquidité a été prise.

Ce que ce n’est pas : une preuve d’intention institutionnelle à elle seule.

Erreur fréquente : Confondre le high/low du corps avec le high/low réel de la bougie.

Mini-exemple : Une longue mèche sous un low peut signaler un sweep, mais seulement si le contexte le confirme.

Liquidité

Définition : zones où les ordres sont probablement concentrés : stops au-dessus des highs, stops sous les lows, ordres autour de niveaux évidents.

À quoi ça sert : comprendre ce que le marché peut chercher avant de se retourner ou de continuer.

Ce que ce n’est pas : une garantie que le prix va immédiatement réagir.

Erreur fréquente : Acheter ou vendre uniquement parce qu’une liquidité vient d’être prise.

Mini-exemple : Un high journalier peut servir de BSL ; une fois pris, on observe la réaction.

BSL / SSL

Définition : BSL = Buy-Side Liquidity au-dessus d’un high ; SSL = Sell-Side Liquidity sous un low.

À quoi ça sert : nommer clairement les cibles de liquidité possibles.

Ce que ce n’est pas : un setup complet ; c’est une destination potentielle.

Erreur fréquente : Croire qu’un sweep de BSL implique automatiquement un short.

Mini-exemple : PDH = souvent BSL ; PDL = souvent SSL.

Sweep / Raid

Définition : dépassement d’un high ou low évident pour prendre la liquidité située derrière ce niveau.

À quoi ça sert : Sert de déclencheur contextuel : après le sweep, on cherche la réaction, le displacement, le MSS ou le FVG.

Ce que ce n’est pas : une entrée instantanée.

Erreur fréquente : Entrer au moment du sweep sans confirmation de rejet ou de structure.

Mini-exemple : Le prix passe sous Asia Low puis réintègre vite : possible fakeout bullish.

DOL — Draw on Liquidity

Définition : cible de liquidité vers laquelle le prix semble être attiré.

À quoi ça sert : donner une direction à la narrative du jour.

Ce que ce n’est pas : toujours le niveau le plus proche ; c’est le niveau le plus logique dans le contexte.

Erreur fréquente : Choisir un DOL après coup pour justifier un trade déjà pris.

Mini-exemple : Si la daily cherche PDH, un long intraday a plus de sens qu’un short tardif.

PDH / PDL

Définition : Previous Day High et Previous Day Low.

À quoi ça sert : Servent de repères journaliers majeurs pour la liquidité et le Daily Bias.

Ce que ce n’est pas : des niveaux magiques : il faut observer la réaction du prix autour d’eux.

Erreur fréquente : Vendre automatiquement PDH ou acheter automatiquement PDL.

Mini-exemple : PDH raid + MSS bearish + FVG peut construire un NY AM reversal short.

Displacement

Définition : mouvement impulsif et déséquilibré, visible par une ou plusieurs bougies directionnelles puissantes.

À quoi ça sert : confirmer qu’une nouvelle livraison du prix est en cours.

Ce que ce n’est pas : juste une grosse bougie isolée dans le vide.

Erreur fréquente : Confondre volatilité aléatoire et displacement structuré.

Mini-exemple : Après un sweep SSL, une bougie haussière forte qui casse un high peut créer un MSS.

Imbalance / Inefficiency

Définition : zone où le prix a livré trop vite, laissant un déséquilibre de cotation.

À quoi ça sert : localiser les zones où le prix peut revenir pour rééquilibrer.

Ce que ce n’est pas : une promesse de retour immédiat.

Erreur fréquente : Traiter chaque déséquilibre comme une entrée sans contexte.

Mini-exemple : Un FVG est une forme structurée d’imbalance.

FVG

Définition : Fair Value Gap à trois bougies, tracé entre B1 et B3 lorsque B2 livre fortement le prix.

À quoi ça sert : trouver une zone de retour possible après displacement.

Ce que ce n’est pas : un signal autonome : contexte, DOL, session et structure comptent.

Erreur fréquente : Prendre un FVG hors session ou après DOL atteint.

Mini-exemple : FVG bullish : zone entre High(B1) et Low(B3), CE au milieu.

B1 / B2 / B3

Définition : les trois bougies servant à identifier un FVG. B2 est souvent la bougie de displacement.

À quoi ça sert : dessiner le FVG sans approximation.

Ce que ce n’est pas : une nomenclature décorative ; elle évite les zones mal tracées.

Erreur fréquente : Tracer le FVG sur les mauvaises bougies parce que la zone paraît jolie.

Mini-exemple : Si B1 et B3 ne se chevauchent pas après B2, une inefficience peut exister.

CE — Consequent Encroachment

Définition : milieu exact du FVG, donc niveau 50 % de l’inefficience.

À quoi ça sert : Sert de repère de test ou d’entrée pédagogique quand le contexte autorise le trade.

Ce que ce n’est pas : CE n’est pas toujours Entrée CE. Le niveau existe même quand le trade est refusé.

Erreur fréquente : Mettre Entrée CE sur tous les FVG, même hors contexte.

Mini-exemple : CE visible — no trade si le FVG est hors narrative.

Mitigation

Définition : retour du prix dans une zone d’inefficience ou d’order block.

À quoi ça sert : observer si la zone réagit ou si elle est consommée.

Ce que ce n’est pas : toujours une opportunité : trop de mitigations dégradent la zone.

Erreur fréquente : Acheter un FVG au troisième test comme s’il était frais.

Mini-exemple : Un FVG fraîchement créé est souvent plus intéressant qu’un FVG déjà revisité trois fois.

Order Block

Définition : zone issue d’une bougie source avant un displacement significatif.

À quoi ça sert : localiser une source potentielle de livraison institutionnelle.

Ce que ce n’est pas : n’importe quelle dernière bougie opposée avant un mouvement faible.

Erreur fréquente : Appeler OB toute bougie rouge avant une hausse.

Mini-exemple : Un OB bullish devient plus crédible s’il est suivi d’un displacement et d’un FVG.

Breaker Block

Définition : ancien order block invalidé qui devient exploitable dans le sens inverse lors du retest.

À quoi ça sert : lire les pièges et changements de rôle d’une zone.

Ce que ce n’est pas : juste un support/résistance classique renommé.

Erreur fréquente : Trader un breaker sans vraie invalidation préalable de l’OB.

Mini-exemple : Ancien OB bullish cassé à la baisse puis retesté = possible breaker bearish.

MSS

Définition : Market Structure Shift, changement de structure significatif après prise de liquidité et displacement.

À quoi ça sert : confirmer qu’un retournement local devient crédible.

Ce que ce n’est pas : une micro-cassure de bruit.

Erreur fréquente : Appeler MSS chaque cassure d’un petit high en M1.

Mini-exemple : SSL sweep + cassure d’un short-term high + FVG = MSS bullish possible.

Premium / Discount

Définition : division d’une range entre moitié haute premium et moitié basse discount.

À quoi ça sert : éviter d’acheter trop haut ou de vendre trop bas.

Ce que ce n’est pas : suffisant pour entrer : il faut setup, timing et liquidité.

Erreur fréquente : Acheter en premium parce qu’un FVG apparaît.

Mini-exemple : Longs préférables en discount ; shorts préférables en premium, selon contexte.

OTE

Définition : Optimal Trade Entry, zone de retracement souvent située entre 62 % et 79 % d’un swing pertinent.

À quoi ça sert : chercher un retracement profond mais logique dans une narrative.

Ce que ce n’est pas : un outil magique ; l’ancrage du swing est le vrai enjeu.

Erreur fréquente : Changer de swing jusqu’à obtenir une zone qui arrange le trade.

Mini-exemple : OTE bearish propre : retracement en premium d’un displacement baissier.

Dealing Range

Définition : range de référence utilisée pour évaluer premium, discount et objectifs.

À quoi ça sert : organiser la lecture du prix dans une structure bornée.

Ce que ce n’est pas : toujours le dernier micro-range visible.

Erreur fréquente : Choisir une range trop petite qui contredit le Daily Bias.

Mini-exemple : Weekly → Daily → H1 : chaque niveau peut avoir sa dealing range.

Sessions / Kill Zones

Définition : fenêtres horaires où la liquidité et la volatilité sont plus exploitables.

À quoi ça sert : filtrer les setups selon le moment de la journée.

Ce que ce n’est pas : une obligation de trader ; une Kill Zone peut très bien ne rien offrir.

Erreur fréquente : Prendre un trade uniquement parce qu’on est en Kill Zone.

Mini-exemple : London peut balayer Asia ; NY AM peut confirmer ou inverser le mouvement.

Asia Range

Définition : range construite pendant la session asiatique.

À quoi ça sert : Sert de référence pour les fakeouts ou breakouts London.

Ce que ce n’est pas : toujours une zone de reversal automatique.

Erreur fréquente : Acheter chaque cassure sous Asia Low sans réintégration.

Mini-exemple : Asia Low sweep + réintégration + MSS + FVG = fakeout bullish possible.

NY AM

Définition : matin new-yorkais, période souvent riche en reversals et continuations.

À quoi ça sert : chercher des réactions autour de PDH, PDL, Asia levels et DOL intraday.

Ce que ce n’est pas : une garantie de mouvement propre tous les jours.

Erreur fréquente : Shorter PDH sans MSS bearish.

Mini-exemple : PDH raid + FVG bearish peut donner un short vers PDL.

PM Session

Définition : session de l’après-midi new-yorkais.

À quoi ça sert : Sert surtout à chercher une continuation si le biais reste intact.

Ce que ce n’est pas : une deuxième journée complète : le mouvement peut déjà être consommé.

Erreur fréquente : Trader PM alors que le DOL du matin est déjà atteint.

Mini-exemple : Lunch sweep + FVG PM + DOL restant = continuation possible.

Daily Bias

Définition : orientation directionnelle privilégiée pour la journée.

À quoi ça sert : filtrer les setups : long, short, prudence ou no trade.

Ce que ce n’est pas : une entrée ; c’est un cadre de sélection.

Erreur fréquente : Forcer des longs parce que le biais est bullish, même sans setup.

Mini-exemple : Score 6/7 bullish : autoriser seulement des longs propres.

Narrative

Définition : histoire conditionnelle du jour reliant contexte, DOL, session et setup attendu.

À quoi ça sert : éviter de lire les setups isolément.

Ce que ce n’est pas : une conviction figée.

Erreur fréquente : Garder une narrative bullish alors que le marché invalide le scénario.

Mini-exemple : Weekly bearish + daily premium + London BSL sweep = attendre short setup.

Top-Down

Définition : lecture du marché du grand timeframe vers le petit timeframe.

À quoi ça sert : aligner direction macro et exécution précise.

Ce que ce n’est pas : empiler des timeframes au hasard.

Erreur fréquente : Prendre un M1 parfait contre un Daily DOL déjà atteint.

Mini-exemple : Weekly donne contexte ; M5/M1 donnent entrée.

SMT

Définition : divergence entre deux actifs corrélés qui ne confirment pas le même high ou low.

À quoi ça sert : Sert de confluence pour détecter un affaiblissement potentiel du mouvement.

Ce que ce n’est pas : une entrée autonome.

Erreur fréquente : Voir une SMT partout sur des différences mineures.

Mini-exemple : ES fait HH, NQ ne confirme pas : possible SMT bearish.

BUY / SELL / NO TRADE

Définition : décisions visuelles de l’atlas : achat, vente, ou refus.

À quoi ça sert : traduire le graphique en action ou abstention.

Ce que ce n’est pas : BUY/SELL ne sont pas des signaux automatiques hors contexte.

Erreur fréquente : Vouloir une entrée sur chaque illustration.

Mini-exemple : Un FVG hors contexte peut afficher CE mais rester NO TRADE.

TP1 / TP2

Définition : objectifs partiels ou principaux du trade.

À quoi ça sert : structurer la sortie et la gestion du risque.

Ce que ce n’est pas : des niveaux décoratifs ; ils doivent correspondre à une liquidité ou un DOL.

Erreur fréquente : Placer TP au hasard pour obtenir un joli ratio.

Mini-exemple : TP1 = liquidité interne ; TP2 = BSL/SSL externe ou DOL principal.

Invalidation

Définition : point ou condition qui annule le scénario.

À quoi ça sert : protéger la discipline et éviter l’acharnement.

Ce que ce n’est pas : seulement le stop loss : c’est parfois une condition de marché.

Erreur fréquente : Déplacer le stop après invalidation pour “laisser respirer”.

Mini-exemple : Si le prix clôture sous un OB bullish, l’idée est invalidée.

R / RR

Définition : R mesure le risque initial ; RR compare potentiel de gain et risque.

À quoi ça sert : juger la qualité d’un trade au-delà du simple win rate.

Ce que ce n’est pas : une excuse pour prendre un mauvais setup avec grand TP.

Erreur fréquente : Chercher 5R sur une journée déjà épuisée.

Mini-exemple : Risque 1R ; TP1 à 1R ; TP2 à 2R ou plus selon liquidité.

Prop Firm Discipline

Définition : règles de survie liées au drawdown, au risque par trade et aux pertes journalières.

À quoi ça sert : rester dans le jeu avant de chercher la performance.

Ce que ce n’est pas : juste une question de stratégie chartiste.

Erreur fréquente : Continuer après 3 pertes pour se refaire.

Mini-exemple : Deux pertes : réduire. Trois pertes : stop journée.

Règle : Une fiche est acquise seulement si tu peux expliquer la zone, les conditions, la décision, l’invalidation et le risque sans relire le texte.

06 — Glossaire visuel minimal

Glossaire

Ce que tu regardes

Le glossaire visuel rassemble les mots qui reviennent sur presque tous les graphiques : liquidité, déplacement, inefficience, structure et décision.

Pourquoi ça compte

Il permet à l’atlas d’être utilisé seul : même si l’étudiant oublie un terme, il retrouve vite son rôle dans la lecture du graphique.

Comment l’utiliser

Quand tu étudies une figure, identifie d’abord quels termes sont présents. Un FVG sans sweep, un MSS sans displacement ou un BUY sans DOL doivent immédiatement t’alerter.

Limite

Ces définitions sont volontairement courtes. Elles ne remplacent pas le manuel, mais elles suffisent pour relire l’atlas et s’entraîner visuellement.

Règle : Une fiche est acquise seulement si tu peux expliquer la zone, les conditions, la décision, l’invalidation et le risque sans relire le texte.

18 — Bougie japonaise : OHLC, corps et mèches

Bases · OHLC

Zone dessinée

La bougie est dessinée avec une mèche complète de High à Low et un corps entre Open et Close. Les wicks comptent toujours.

Pourquoi elle compte

Tout le reste du manuel repose sur cette précision : un High ou un Low se mesure sur la pointe de la mèche, pas sur le corps.

Point d’entrée / décision

Aucune entrée ici : ce visuel sert à apprendre ce que le graphique mesure réellement.

Invalidation / erreur

Erreur fréquente : tracer une zone sur le haut/bas du corps au lieu du vrai High/Low de la bougie.

Règle : Une fiche est acquise seulement si tu peux expliquer la zone, les conditions, la décision, l’invalidation et le risque sans relire le texte.

19 — Types d’ordres : où se placent Market, Limit et Stop

Bases · ordres

Zone dessinée

Le schéma place les ordres par rapport au prix actuel : Buy Limit sous le prix, Sell Limit au-dessus, Buy Stop au-dessus, Sell Stop sous le prix.

Pourquoi elle compte

Cela explique pourquoi les stops se concentrent au-dessus/sous les niveaux et deviennent des pools de liquidité.

Point d’entrée / décision

Dans ce modèle, l’entrée se fait par Limit dans une zone validée, pas par Buy Stop/Sell Stop de breakout.

Invalidation / erreur

Erreur : entrer en Buy Stop sur la cassure alors que le modèle attend souvent le sweep puis le retour.

Règle : Une fiche est acquise seulement si tu peux expliquer la zone, les conditions, la décision, l’invalidation et le risque sans relire le texte.

Vocabulaire — Premium, Discount et Equilibrium

Glossaire · range

Définition

Premium = moitié haute d’une range ; Discount = moitié basse ; Equilibrium = 50 % de la range.

Utilité

Cette notion filtre les entrées : on cherche plus volontiers des achats sous 50 % et des ventes au-dessus de 50 %.

Ce que ce n’est pas

Ce n’est pas une entrée automatique. C’est un filtre de localisation, pas un signal complet.

Mini-exemple

Si le prix retrace sous le 50 % d’un swing bullish et crée un FVG, l’achat devient mieux localisé qu’en haut de range.

Règle : Premium/Discount indique où il est rationnel de chercher un prix avantageux dans une range.
