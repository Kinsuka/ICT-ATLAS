ICT Atlas - README V57
======================

Objectif
--------
V57 corrige la dette visible signalee dans la critique externe :

- repositionnement public du cours ;
- suppression des mentions de versions internes dans le contenu visible ;
- verification de la navigation 29 lecons ;
- nettoyage des doublons potentiels de logique institutionnelle ;

Positionnement retenu
---------------------
Titre public : ICT Atlas
Promesse : Comprendre ICT une bonne fois pour toutes.

Le cours ne se presente plus comme "De Zero a Pro". Il vise plutot le trader
qui a deja croise ICT/SMC, reconnait certains patterns, mais veut ancrer les
fondations pour filtrer le bruit et passer du concept au graphique reel.
