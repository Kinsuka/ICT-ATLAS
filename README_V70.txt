ICT Atlas - V70

Objet
- Ajout d'une leçon dédiée : 38-smt-divergence.html.
- Objectif pédagogique : utiliser SMT comme confluence de contexte entre marchés corrélés, pas comme setup autonome.

Pourquoi
- SMT est souvent cité dans ICT/SMC, mais très mal utilisé.
- Sans chapitre dédié, l'étudiant risque de voir des divergences partout et d'entrer sans liquidité, sans réaction et sans plan.
- La leçon arrive après DOL/targets afin de relier la non-confirmation à une vraie zone de liquidité.

Contenu ajouté
- Définition SMT : non-confirmation entre marchés corrélés.
- Schéma large SMT bearish : un marché prend BSL, l'autre ne confirme pas.
- Schéma SMT bullish : un marché prend SSL, l'autre défend son low.
- Checklist SMT : marchés, niveau, timing, contexte, confirmation.
- Cas A/B/C : SMT propre, divergence faible, corrélation cassée.
- Process : corrélation -> liquidité -> SMT -> réaction -> setup.
