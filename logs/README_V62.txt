ICT Atlas - V62 - Bibliotheque de cas replay verifiables

Objectif
Preparer l'integration de vrais cas replay sans inventer de dates, de marches
ou de resultats non verifies.

Changements
- Nouvelle page support : replay-cases.html
- Ajout de slots de cas a valider :
  - liquidite propre ;
  - cible deja consommee ;
  - sweep + rejet ;
  - breakout accepte ;
  - failed breakout ;
  - entree causale complete ;
  - entree trop tot ;
  - TP trop proche ou trop ambitieux ;
  - bon no trade ;
  - apres perte / discipline.
- Ajout du template : templates/cas-replay-validation.md
- Ajout de liens depuis :
  - 30-replay-lab.html
  - 08-quiz.html
  - 15-index-concepts.html
  - ressources-pratiques.html
- Mise a jour de templates/README.md et de la page ressources.

Principe
Un cas ne devient pas un cas valide du cours sans :
- capture avant decision ;
- decision ecrite avant resultat ;
- capture apres revelation ;
- classification ;
- correction.

Note
La V62 ne pretend pas fournir des cas historiques deja verifies. Elle cree la
structure propre pour les accueillir sans biais de hindsight.

Validation attendue

- Liens vers replay-cases.html et templates/cas-replay-validation.md valides.
- Aucun bruit de version visible dans les pages publiques.
