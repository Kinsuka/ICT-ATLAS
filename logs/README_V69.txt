Objet
- Ajout d'une leçon dédiée : 37-dol-targets-hierarchie.html.
- Objectif pédagogique : clarifier DOL, TP1, TP2, target maximale raisonnable, sécurisation et refus du trade.

Pourquoi
- Après OTE / Dealing Range, l'étudiant sait où attendre le prix.
- Il doit maintenant savoir si le trade vaut encore le risque : cible disponible, cible fraîche, zone opposée, distance suffisante.
- Le cours évite ainsi l'erreur classique : bonne entrée, mauvaise sortie.

Contenu ajouté
- Définition du DOL comme cible et comme filtre.
- Schéma large : entrée, invalidation, TP1, TP2/DOL, zone de protection.
- Tableau : liquidité interne, equal highs/lows, PDH/PDL/Asia, liquidité externe, PD Array opposée.
- Cas A/B/C : target propre, target trop proche, DOL déjà consommé.
- Schéma de sécurisation progressive : entrée, +1R, TP1, zone opposée, TP2/DOL.
- Checklist : target visible, distance suffisante, cible fraîche, zone opposée.
