# ICT Atlas - Templates pratiques

Ces fichiers servent a transformer le cours en pratique documentee.

- `journal-trades.csv` : journal de trades et de no trades.
- `backtest-ict.csv` : table de backtesting orientee setup ICT.
- `checklist-session.md` : checklist avant / pendant / apres session.
- `review-post-session.md` : revue post-session et psychologie.
- `plan-trading-ict.md` : plan de trading a personnaliser.
- `regles-prop-firm.md` : cadre defensif pour challenge prop firm.
- `replay-lab.csv` : fiche de cas pour entrainement bar replay.

Les fichiers CSV s'ouvrent dans Excel, Numbers, Google Sheets ou LibreOffice.
Le but n'est pas de remplir beaucoup de cases, mais de garder une preuve stable
de ce qui a ete vu, decide, execute et respecte.
